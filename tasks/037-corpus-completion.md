# Task 037 — Complete the beitie corpus and record what the images need

Audit the existing works and objects against the canonical coverage table, add the
missing inscriptions and modelbooks that have citable institutional evidence, and
complete the fields that existing records left empty where a cited source supports
the value. Keep the schema, naming and file conventions unchanged. Record image
leads and their licence or access blockers instead of bundling images whose rights
cannot be read.

Scope:

- Add works and physical objects for the canonical gaps: 平复帖, 十七帖,
  洛神赋十三行, 好太王碑, 始平公造像记, 虞恭公碑, 颜氏家庙碑, 万岁通天帖,
  胆巴碑, 三门记, 三希堂法帖.
- Add the places and sources each new record needs; do not reuse a holding claim
  for a different object.
- Close the bilingual note backlog: every work and place note that carried only an
  English counterpart gets a Chinese translation with the same count and order.
- Document the image search: what was found, what licence each candidate states,
  and why no `media` item shipped.
- Regenerate the knowledge catalogue, run `npm run check`, and record the outcome.
