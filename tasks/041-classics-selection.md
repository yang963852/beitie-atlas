# Task 041 — Add a chronologically ordered classics selection

Research a teaching-oriented selection of canonical steles and modelbooks across the
main scripts and periods, score each candidate for canonicity, historical
representativeness and classroom usability, and add the accepted entries to the
Markdown knowledge library. Keep the existing schema, stable-ID naming, bilingual
prose and catalogue ordering unchanged. Do not duplicate a work already represented,
and do not promote an attribution beyond what the cited source states.

Scope:

- Audit the existing 87 works by period and script; identify structural gaps rather
  than adding more of what is already dense.
- Select 11 works that fill empty periods (Five Dynasties, Southern Song, Republican
  period) and missing script links (small-script origins, Tang seal script, wild
  cursive, slender-gold script, Northern Qi cliff characters, Ming late running-
  cursive, Wu Changshuo's Stone Drum line).
- Add one physical object per work, with its own carrier, date and holding; keep
  lost originals and later recarvings separate from what survives.
- Add the places and sources each record needs. Prefer museum, library, heritage or
  government pages; mark newspaper features as such and do not use them for a
  holding claim.
- Record unresolved disagreements (line counts, character counts, recutting,
  attribution) as bilingual notes instead of choosing a tidier figure.
- Write the selection report with the evaluation matrix and the rejected candidates.
- Regenerate the catalogue, run `npm run check`, and record the outcome in a delivery
  report.
