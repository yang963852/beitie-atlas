# 明 王宠 楷书送陈子龄会试诗页

故宫博物院藏品条目。记此页纸本、册页，纵 23.2 厘米、横 36.3 厘米，楷书十八行，钤「太原王宠」「王履吉印」；文中「陈子龄」为王宠门人。条目附王宠小传（1494—1533，字履仁，后字履吉，号雅宜山人，吴县人，邑诸生，累试不取，贡入太学），称其「工诗文，精书法，风格婉丽遒逸」，与祝允明、文徵明并称吴中三家，为唐寅姻亲。馆方并说明此页「极尽涩拙之态」，按楷书风格变化当为晚年所书。
