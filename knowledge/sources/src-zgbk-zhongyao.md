# 钟繇

中国大百科全书（第三版）网络版的钟繇条目，撰者王玉池。记其生卒、官职封爵、《宣和书谱》的评语，以及「五表六帖」的存佚：古临本《荐季直表》毁于民国年间，只有影印本传世；刻帖有《宣示表》《贺捷表》《力命表》《墓田丙舍帖》等。
