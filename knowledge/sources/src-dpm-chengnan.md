# 元 杨维桢 行书张栻城南杂咏卷

故宫博物院藏品条目。记此卷纸本、纵 31.6 厘米、横 216.6 厘米，《石渠宝笈三编》著录，贮延春阁；书于至正二十二年（1362），杨氏时年六十七。文中叙其缘起：虞子贤藏朱熹《城南唱和》手迹而张栻原诗已佚，遂请杨维桢追和并补书。附吴宽「大将班师，三军奏凯，破斧缺斨，倒载而归」与徐有贞「铁崖狂怪不经，而步履自高」两评，并记明清递藏，1922 年溥仪以「赏溥杰」名义携出，1959 年入藏故宫。
