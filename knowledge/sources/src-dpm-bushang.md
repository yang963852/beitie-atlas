# 镇院之宝——唐欧阳询行楷书卜商读书帖页

故宫博物院「镇院之宝」栏目关于此页的专文。记帖为纸本墨笔，六行，释文为卜商答孔子问书一段；钤安岐「安」朱文圆印、「仪周鉴赏」白文方印，四角存古印印痕。文中说明此页清内府时与欧阳询《张翰帖》、王献之《东山松帖》、赵孟頫《道场何山诗》等十二帖合装为《法书大观》册，清末被太监藏于漱芳斋炕板之下，抗战期间清点文物时发现；并记《宣和书谱》卷八、《式古堂书画汇考》《大观录》《墨缘汇观》著录，刻入《三希堂法帖》第三册。启功、徐邦达、王以坤、刘九庵的鉴定意见为「唐人摹本，定名为《唐摹欧阳询卜商帖》」。
