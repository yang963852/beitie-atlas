# 唐 虞世南 行书汝南公主墓志铭卷

上海博物馆藏品条目。记此卷为纸本、纵 25.9 厘米、横 38.4 厘米，书于贞观十年（636），作者时年七十九；附虞世南小传（558—638，字伯施，浙江余姚人，官秘书少监，封永兴县公，师智永，初唐四家之一），并注明「亦有米临之说」。
