# 上博历代书法馆常设展换展，新增九件书画精品

上海博物馆 2019 年换展公告。其中一节记王宠小楷《包山集》：1520 年王宠游昆陵包山，作游诗数首结为《包山集》；1526 年冬过鸿溪宿友人补庵居士处，居士索书；次年即以小楷抄录二十二首寄之。文嘉见后称「天才妙绝」，后人普遍推为王氏小楷代表作。文中并记刘九庵对此作是否出自王宠之手的疑问。
