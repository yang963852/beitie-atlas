# 司马悦墓志

河南博物院藏品页。记墓志为青石质，1979 年元月河南孟县城关斗鸡台村司马悦墓中出土；志盖长一百一十厘米、宽七十八厘米、厚八厘米，上刻「墓志盖」三字，存孟州市文化馆；志石长一百零八厘米、宽七十八厘米、厚十二厘米，1997 年入藏河南博物院。志刻于北魏永平四年（511）二月十五日，正书二十二行，行三十三字，除去空格实有六百六十一字，字迹清晰。志主司马悦（462—508）历任征虏将军、豫州刺史，封渔阳县开国子，永平元年为白早生所杀。馆方评其书「刚健隽逸，笔画洗练爽明」，结构「以方严为尚」，「代表了魏碑书法方严紧舒一派的书法艺术精神」。
