# 黄庭坚草书诸上座帖卷

故宫博物院藏品页。记帖为纸本手卷，草书，九十二行，纵三十三厘米，横七百二十九点五厘米；黄庭坚为友人李任道录写五代金陵僧人文益的《语录》，署款「山谷老人书」，钤「山谷道人」朱文方玺。后纸有明吴宽、清梁清标题跋各一段。卷前后及隔水钤宋「内府书印」「绍兴」「悦生」，元「危素私印」及明李应祯、华夏、周亮工，清孙承泽、王鸿绪，近代张伯驹等鉴藏印。文中并记此帖自南宋高宗内府、贾似道以下直至张伯驹捐献的递藏经过，及都穆《寓意编》、文嘉《钤山堂书画记》、张丑《清河书画舫》、卞永誉《式古堂书画汇考》、孙承泽《庚子消夏记》、《石渠宝笈初编》等书著录。
