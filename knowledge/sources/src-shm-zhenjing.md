# 元 杨维祯 行书真镜庵募缘疏卷

上海博物馆藏品条目。记此卷为纸本、纵 33.3 厘米、横 278.4 厘米，卷装，行书；附杨维祯小传（1297—1370，字廉夫，号铁崖，浙江诸暨人，泰定四年进士，官杭州四务提举，元末避乱徙松江），称其「工书，用笔多章草意」，并说明此卷是晚年为真镜庵所撰的募缘启事，庵址原在浦东。
