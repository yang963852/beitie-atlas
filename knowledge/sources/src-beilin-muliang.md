# 穆亮墓志

西安碑林博物馆藏品页。记志高六十六厘米，宽五十九厘米，志文二十行，满行二十二字，楷书，刻于北魏景明三年（502）。1925 年河南洛阳城东北西山岭头西南出土，1938 年于右任捐藏西安碑林。馆方评其书「用极其严正的楷书书写，其势如雄师列队，行伍成壮，字字皆有强悍的气概」，风格与《张猛龙碑》接近。志主穆亮字幼辅，北魏献文帝时封长乐王，宣武帝即位后拜尚书令、司空，封顿丘公。
