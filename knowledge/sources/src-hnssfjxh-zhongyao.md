# 钟繇

河南省书法家协会网站转载的《中国书画报》文章，逐条介绍钟繇的几件刻帖。文中给出《荐季直表》书于魏黄初二年（221）、《贺捷表》书于建安二十四年（219），并记《贺捷表》有郁冈斋帖本、《墓田丙舍帖》刻入《墨池堂》《快雪堂》等。所引《宣和书谱》语与本库另一来源相合。
