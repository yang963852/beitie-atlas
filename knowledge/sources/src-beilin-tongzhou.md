# 同州三藏圣教序碑

西安碑林博物馆的碑刻条目。记此碑立于唐龙朔三年（663）六月，碑文为贞观二十二年（648）太宗为玄奘新译经典所制《圣教序》及太子李治所作《圣教序记》，褚遂良书；螭首方趺，碑高 350 厘米；原存陕西大荔，1972 年入藏碑林。条目附褚遂良小传，并引清人李宗瀚语「遒丽处似虞，端劲处似欧」。
