# 道因法师碑

西安碑林博物馆藏品页。记碑为唐龙朔三年（663）十月镌立，李俨撰，欧阳通书；螭首龟趺，通高三百一十二厘米，北宋移存西安碑林。碑主道因法师（587—658）隋末避乱益州多宝寺，后赴京止大慈恩寺，与玄奘证译梵本。页末记欧阳通（625—691）为欧阳询之子，初拜兰台郎，仪凤中迁中书舍人，封渤海公，天授初年转司礼卿判纳言事，二年为相，因反立武承嗣为太子，为酷吏来俊臣陷害而死；工楷书，得父法而险峻过之，父子齐名，号「大小欧阳」；传世碑版仅有二种，另一为《泉男生墓志》。
