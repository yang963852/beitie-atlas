# 张即之行书双松图歌卷

故宫博物院藏品页。记卷为绢本手卷，行书，七十二行，一百四十四字，纵三十三点八厘米，横一千一百九十六厘米；书杜甫《戏为双松图歌韦偃画》。款署「张即之七十二岁写。时积雨连霉，槐龙舞翠，与客小饮醉中戏书」，钤「张」「张氏」「即之」印。馆方据自识「七十二岁」定为南宋理宗宝祐五年（1257）书；卷前有苏轼古柏图，馆方注明非真迹；尾纸有明洪武时陈新、夏彦良二跋。清缪日藻《寓意录》、清内府《石渠宝笈·初编》著录。
