# 行书跋沈尹默论书札卷（草稿）

## 中文

1976年，[赵朴初](../people/zhao-puchu.md)在[沈尹默](../people/shen-yinmo.md)的论书札后题跋，追念这位曾与他以诗词相和的朋友。上博将赵所写的这一段定为行书，记为高20.8厘米、宽10.0厘米。沈氏原札另记尺寸，书写年月尚待查明。[上海博物馆，详细年代、尺寸与简介](https://www.shanghaimuseum.net/mu/frontend/pg/article/id/CI00160807)

读题名时，可先在“跋”字两侧分别写下两个人的名字。再核对馆方的尺寸栏，看看各自对应卷上的哪一段。

## English

In 1976 [Zhao Puchu](../people/zhao-puchu.md) added a colophon to [Shen Yinmo](../people/shen-yinmo.md)’s writing on calligraphy in memory of the friend who had exchanged poems with him. The Shanghai Museum describes Zhao’s contribution as running script, 20.8 cm high by 10.0 cm wide. It records separate measurements for Shen’s text. Its writing date remains open. [Shanghai Museum, date, measurements and description](https://www.shanghaimuseum.net/mu/frontend/pg/article/id/CI00160807)

In the Chinese title, write one name on each side of 跋 (colophon). Match each name to a section of the scroll using the catalogue’s measurements.
