# 苦笋帖

## 背景

### 中文

《苦笋帖》是上海博物馆著录的唐代怀素书札，藏品页定其书体为草书。旧页转录全文为：“苦筍及茗异常佳，乃可迳来。怀素上。”并记作二行十四字。现行藏品页称此帖为致友人短札，并评价它是迄今传世怀素作品中唯一没有争议的真迹。这些真伪与评价均保留为馆方陈述。[上海博物馆现行藏品页](https://www.shanghaimuseum.net/mu/frontend/pg/article/id/CI00000593) · [上海博物馆旧页](https://www.shanghaimuseum.net/resource/winchance/n11.html)

旧页另以“草、行间出”形容此帖。本库的结构化书体从现行藏品页的“工艺：草书”，不把旧页的形容改写为另一种确定性归类。[上海博物馆旧页](https://www.shanghaimuseum.net/resource/winchance/n11.html)

### English

The Shanghai Museum catalogues the Letter on Bitter Bamboo Shoots as a Tang letter by Huaisu in cursive script. The legacy page transcribes it as “苦筍及茗异常佳，乃可迳来。怀素上。” and records two lines of fourteen characters. The current collection entry describes it as a short letter to a friend and calls it the only undisputed authentic surviving work by Huaisu. Both the authenticity statement and the evaluation remain attributed to the museum. [Shanghai Museum collection entry](https://www.shanghaimuseum.net/mu/frontend/pg/article/id/CI00000593) · [Shanghai Museum legacy page](https://www.shanghaimuseum.net/resource/winchance/n11.html)

The legacy page also describes the writing as “草、行间出”, a formulation involving both cursive and running script. The structured script field follows the current entry’s explicit “草书”; the older description is retained here without turning it into a second categorical classification. [Shanghai Museum legacy page](https://www.shanghaimuseum.net/resource/winchance/n11.html)
