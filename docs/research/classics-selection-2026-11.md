# 中国书法史经典碑帖筛选与增补（2026-11）

本文记录 2026 年 11 月一次按时间演进补齐馆藏结构的选目工作。结论已写入 `knowledge/works/`、`knowledge/objects/`、`knowledge/places/` 与 `knowledge/sources/`；本文保留评估口径、入选理由、未选条目和证据限制，供编辑复核与课堂备课使用。

## 1. 评估口径

选目不是“名作排行榜”，而是为一座可读、可教、可查证的碑帖库补结构。三个维度按下列权重排序，遇到冲突时以证据可核性优先。

| 维度 | 权重 | 具体判断 |
| --- | --- | --- |
| 经典性 | 40% | 历代著录、题跋与临习传统；是否被反复推为某一书体或技法的范本；馆方是否列为一级文物或重点藏品 |
| 历史代表性 | 35% | 是否处在书体、风格或制度（碑、帖、摩崖、墓志、写经、丛帖）的转折点上；能否代表一个时期 |
| 教学适用性 | 25% | 字迹清晰度、篇幅与字数、技法是否便于分解讲解；是否有可靠拓本、印本或墨迹可看 |

一票否决条件：

- 找不到馆方、政府、图书馆或可核书目支撑其题名、年代与收藏；
- 与现有条目重复，或只是同一系统的又一翻刻；
- 只剩传说，没有实物、拓本或明确刻本载体。

评分只用于排序，不写进数据字段。记录里只放可回到出处的陈述；评价性判断留在本文和作品背景中，不用来冒充史实。

### 3.1 宣示表

- **朝代/时期**：三国·曹魏，写作年份未记。
- **书体**：小楷。
- **作者/书者**：表文为钟繇；传世刻本多称据王羲之临本摹刻。
- **历史地位**：钟繇被尊为“正书之祖”，《宣示表》是现存钟繇小楷中最成熟的一件，也是《淳化阁帖》《大观帖》系统里反复出现的楷书源头。
- **代表意义**：它把隶书的波磔收进楷书的框架，正处在隶楷之交；真迹不存、只靠刻本流传，又是“帖”的传播方式的典型样本。
- **教学价值**：十八行、字数适中，结体宽博而多扁方，适合讲楷书如何从隶书脱出；同时可讲“原迹—临本—刻本”的层累，不宜当作钟繇手迹临摹。
- **入选理由**：三国一段原本只有一方吴碑，缺曹魏楷书源头；此帖补上“楷书之祖”，且与《洛神赋十三行》《灵飞经》构成小楷从源头到唐写经的序列。

### 3.2 张玄墓志

- **朝代/时期**：北魏普泰元年（531）十月。
- **书体**：楷书。
- **作者/书者**：未署名。
- **历史地位**：魏碑墓志的代表作，清代碑学兴起后被何绍基、包世臣等反复推重。
- **代表意义**：方圆兼备、结体扁方而含隶意，既有北碑的峻拔，又见楷法的整饬，是北魏墓志一路的典型。
- **教学价值**：字口清晰，字数适中，适合从墓志讲魏碑的“刀味”与书写感；原石已佚，只剩孤本拓册，也适合讲拓本作为载体的重要性。
- **入选理由**：现有南北朝一段全是碑、摩崖与造像记，缺墓志；《张玄墓志》是这一体例最常被指定为入门范本的一种。

### 3.3 泰山经石峪金刚经

- **朝代/时期**：北齐（无年月，依笔势推定）。
- **书体**：隶楷，摩崖大字。
- **作者/书者**：未署名。
- **历史地位**：中国现存规模最大的佛教摩崖刻经之一，康有为《广艺舟双楫》推为“榜书之宗”。
- **代表意义**：以隶书为骨，兼用楷、篆笔意，把隶楷之变放大到字径五十厘米的尺度；同时也是北朝佛教刻经制度的实物。
- **教学价值**：单字大、笔画关系清楚，适合讲大字的结构与中锋行笔；残损与剥蚀也适合讲“拓本不能等同于原石”。
- **入选理由**：南北朝已有《石门铭》《郑文公碑》等摩崖，但缺北齐这一路隶楷大字；此经补上“榜书”教学缺口。

### 3.4 灵飞经

- **朝代/时期**：唐开元二十六年（738）前后。
- **书体**：小楷。
- **作者/书者**：传钟绍京；馆方只标“传”，未确认书写者。
- **历史地位**：唐代小楷名品，明代董其昌推为唐代小楷精品，刻入《渤海藏真》后成为明清以来最通行的小楷范本之一。
- **代表意义**：写经体的精练与二王楷法的雅致合在一处，代表唐代宫廷写经的最高水平；四十三行墨迹与三种刻本的并存，也是“墨迹—刻帖”关系的教材。
- **教学价值**：字径一厘米上下，笔路清晰，起收、转折、轻重都可分解；篇幅短，适合初学与课堂示范。
- **入选理由**：小楷原有《洛神赋十三行》，偏古淡；缺一件法度完备、可直接上手的唐楷小楷。《灵飞经》正好补这一层，并把“写经”这一制度性书写带入库中。

### 3.5 三坟记

- **朝代/时期**：唐大历二年（767）。
- **书体**：小篆。
- **作者/书者**：李季卿撰文，李阳冰篆书。
- **历史地位**：李阳冰代表作，唐篆复兴的标志；后人以“二李”并称李斯与李阳冰。
- **代表意义**：承秦《峄山碑》的玉箸笔法，线条匀细、结体修长，是秦篆之后小篆谱系的关键一环。
- **教学价值**：篆法规矩、对称工稳，适合讲小篆的中锋、等粗线条与结体均衡；由秦篆到唐篆的对比，也便于课堂演示“同一种书体如何随时代变形”。
- **入选理由**：库中篆书有秦刻三石与清人篆书，中间缺唐篆；《三坟记》是补这一段最常用、也最容易找到馆方著录的一件。

### 3.6 古诗四帖

- **朝代/时期**：唐（无年款）。
- **书体**：狂草。
- **作者/书者**：传张旭。
- **历史地位**：唐代狂草的标志性长卷，辽宁省博物馆藏国家一级文物，展览说明以“草圣典范”列出。
- **代表意义**：把今草的连绵推向字形大小错落、行气不断的一路，是张旭“狂草”传统的核心实物；与怀素《自叙帖》构成唐代狂草的双峰。
- **教学价值**：适合讲草书的使转、速度与字势关系；但难度高，宜作欣赏与提高阶段的范本，不宜作初学临本。
- **入选理由**：草书已有《十七帖》（今草）、《书谱》（小草）、《自叙帖》（狂草），但缺张旭；此卷补上狂草的源头人物，也使“颠张醉素”得以对读。

### 3.7 韭花帖

- **朝代/时期**：五代（帖末只署七月十一日，无年）。
- **书体**：行楷。
- **作者/书者**：杨凝式。
- **历史地位**：五代书法仅存的几件名迹之一，清内府旧藏，入《石渠宝笈》，刻入《三希堂法帖》，被后人称为“天下第五行书”。
- **代表意义**：字距行距疏朗、用笔时收时放，上承唐法而下开宋人尚意；杨凝式是由唐入宋的关键人物。
- **教学价值**：七行六十余字，篇幅短，行楷相间，适合讲“疏朗章法”和“收放关系”；也是从唐楷过渡到宋代行书的好教材。
- **入选理由**：五代十国在增补前是整段空白。此帖一件即可撑起这一时期，且与北宋苏、黄、米形成直接的风格前史。

### 3.8 秾芳诗帖

- **朝代/时期**：北宋（无年款）。
- **书体**：瘦金书。
- **作者/书者**：赵佶（宋徽宗）。
- **历史地位**：传世徽宗书迹中字最大的一件，瘦金书的代表；台北故宫博物院藏。
- **代表意义**：瘦金书把起笔、收笔与转折的锋芒全部留在纸上，是楷书系统中极为特殊的一支；也体现北宋宫廷书画的审美与制度。
- **教学价值**：笔画关系极清楚，起收、顿挫、转折都可放大讲解；但习气重，适合作为“风格识别”与“笔法分析”教材，不宜作入门临本。
- **入选理由**：北宋一段宋四家齐备，却缺瘦金书这一独特书体；此帖补上书体多样性，也补上帝王书家这一类型。

### 3.9 陆游自书诗卷

- **朝代/时期**：南宋嘉泰四年（1204）。
- **书体**：行草。
- **作者/书者**：陆游。
- **历史地位**：陆游八十岁所作，辽宁省博物馆藏，被视为其书法最高代表、南宋行书的典范。
- **代表意义**：行草相杂、笔势连绵而墨色自然，是南宋文人“诗书合一”的日常书写；也让南宋一段不再空白。
- **教学价值**：篇幅较长，适合讲行草的连断、墨色与行气；诗卷形制也便于讲“书写情境”对风格的影响。
- **入选理由**：南宋在增补前是整段空白。陆游诗名掩盖书名，此卷正好补上南宋行草，并与北宋苏、黄、米形成时段衔接。

### 3.10 王铎行草书自书诗卷

- **朝代/时期**：明崇祯十二年（1639）正月。
- **书体**：行草。
- **作者/书者**：王铎。
- **历史地位**：王铎中年书风形成期的典型作品，故宫博物院藏；王铎是明末清初行草的代表。
- **代表意义**：笔势连绵而字间连带不多，靠行气贯通，呈现“纵而能敛”的一路；上承钟繇、二王、颜真卿、米芾，下开清初大幅行草。
- **教学价值**：长卷便于讲行气的贯通与字距、行距的控制；也可与董其昌的疏朗一路对读，讲明末两种行草取向。
- **入选理由**：明代已有祝允明、文徵明、董其昌，但缺明末长卷行草的高峰；王铎一件即可补上，并与清初书法衔接。

### 3.11 吴昌硕临石鼓文轴

- **朝代/时期**：1915 年（民国）。
- **书体**：篆书。
- **作者/书者**：吴昌硕。
- **历史地位**：吴昌硕七十一岁所书，故宫博物院藏；清民之际篆书与金石画派的代表。
- **代表意义**：把《石鼓文》的横势改为纵势，结字参差取姿，用笔沉厚而线条粗细多变，是“临摹转为创造”的典型。
- **教学价值**：可与库中《石鼓文》原拓对读，讲临摹如何取舍、如何形成个人面目；也适合讲清代碑学之后的篆书走向。
- **入选理由**：清代篆隶复兴已有邓石如、赵之谦、伊秉绶，缺吴昌硕一路；此轴同时把库中《石鼓文》的接受史接到 20 世纪。

- **隶书**：东汉诸碑 → 泰山经石峪（隶楷摩崖）→ 伊秉绶（清隶）。
- **行书/行草**：兰亭序、伯远帖 → 祭侄文稿 → 韭花帖 → 宋四家 → 陆游 → 王铎。

## 5. 未入选的候补与理由

| 候补 | 理由 |
| --- | --- |
| 黄庭经、荐季直表 | 与《宣示表》《洛神赋十三行》同属钟王小楷系统，已有两条；再增会造成重复，留待替换而非并置 |
| 大观帖、绛帖、汝帖 | 与《淳化阁帖》同属丛帖系统，版本与卷次问题复杂，宜单独立项，不宜在一次结构补缺中草率加入 |
| 毛公鼎、散氏盘 | 金文重器，但不属碑帖载体；本项目以碑、帖、摩崖、墓志、写经为范围，故不收 |
| 索靖月仪帖 | 章草已有《平复帖》代表；《月仪帖》拓本系统与作者归属待核，证据不足 |
| 杨维桢、徐渭、张瑞图 | 明代个性书风重要，但与已选王铎同属明末行草扩张一路；一次增补只取一个高峰，避免时段过密 |
| 辽、金碑刻 | 需要先确定具有教学代表性且馆方著录可靠的单件，暂不凑数 |

## 6. 证据与限制

- 11 条新记录全部为 `draft`，等待编辑复核；正式出版门槛仍会拦截。
- 宣示表的“宋拓”为旧签与著录用语，册内诸帖是否同为宋拓未见逐开鉴定。
- 张玄墓志的行款有二十行与十二行两说，字数亦有出入，未据拓本复核。
