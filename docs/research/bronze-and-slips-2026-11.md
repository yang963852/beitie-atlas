# 金文与简牍增补（2026-11）

业主指示把收录范围从碑帖扩展到金文与简牍。本文记录选目、分类决定、证据与限制。记录已写入 `knowledge/works/`、`knowledge/objects/`、`knowledge/places/` 与 `knowledge/sources/`。

## 1. 为什么收录

碑帖之学本以金石为源。金文是青铜器上的铸刻文字，清代碑学兴起后，金文拓本一直是篆书学习的核心材料；简牍是纸张普及前的墨迹，提供了刻石看不到的运笔与书写节奏。两者补上碑帖的两个盲区：

- **金文**：篆书在秦刻石之前的形态，从西周早、中、晚期到战国中山，能看到铸造、刻制与书写的关系。
- **简牍**：从战国楚简、秦简、西汉隶书、东汉章草到孙吴隶楷，墨迹完整呈现隶楷之变的日常书写面。

## 2. 分类决定

现有数据只有 `bei`／`tie` 两类，实物类型没有青铜器。处理如下：

| 问题 | 决定 | 理由 |
| --- | --- | --- |
| 作品分类 | 金文归 `bei`，简牍归 `tie` | 金文长期以拓本行世，属金石碑拓传统；简牍是墨迹，属帖学所见的手写系统 |
| 实物类型 | 新增 `bronze-vessel`（青铜器） | 铜器原器既不是原石、摩崖，也不是拓本；用 `rubbing` 会把拓本冒充原器 |
| 简牍实物类型 | 沿用 `ink-manuscript`（墨迹） | 竹木简上的墨书就是墨迹；尺寸与材质写入 `dimensions` 与待考 |
| 书体字段 | 用具体名：金文、中山篆、楚系简帛书、秦隶、汉隶、章草、吴简隶楷 | 不把多种书体压成“篆书”“隶书”一个词 |

新增类型只影响实物标签、排序与地图“存世原物”筛选；未改编译器结构、未改页面布局。

### 选目逻辑

- **金文三段**：西周早期《大盂鼎》的雄浑、中期《史墙盘》的整饬、晚期《散氏盘》的奇逸与《毛公鼎》的庄重，构成西周金文的主线；战国《中山王厝鼎》补上列国文字中装饰性最强的一支。
- **简牍一线**：楚简（源头）→ 秦简（篆隶之交）→ 西汉《仪礼》简（成熟汉隶）→ 东汉劾状（章草）→ 孙吴田家莂（隶楷之交）。五个点连起来，就是纸前墨迹的书法史。
- 未选《虢季子白盘》《大克鼎》：与已选西周晚期诸器风格相近，一次增补不重复同一段。
- 未选马王堆帛书：属帛书，不在“简牍”范围，留作下一批。

## 4. 教学价值

| 作品 | 看什么 | 怎么用 |
| --- | --- | --- |
| 大盂鼎 | 字形的庄重、行气的整饬 | 金文入门，先看单字结构，再看十九行的排布 |
| 史墙盘 | 整齐中的轻重变化 | 与《大盂鼎》对读，讲西周中期风格的收束 |
| 散氏盘 | 欹侧、跳宕、字距不匀 | 讲“草篆”与章法的不规则；不适合初学结构 |
| 毛公鼎 | 长篇铭文的通篇气脉 | 高级临习；讲长篇如何保持统一 |
| 中山王厝鼎 | 修长、尖入尖出、装饰性 | 讲战国文字的装饰化与地域差异 |
| 郭店楚简 | 秀丽欹侧、提按分明 | 楚简书法入门；讲简册行款 |
| 睡虎地秦简 | 短直笔画、扁方结体、篆意未退 | 讲篆隶之交；与汉碑隶书对读 |
| 武威仪礼简 | 蚕头燕尾、字距疏朗 | 汉隶墨迹范本；与《熹平石经》刻隶对读 |
| 居延劾状 | 章草的收笔与字字独立 | 章草入门；讲边塞文书的日常书写 |
| 走马楼田家莂 | 方整、峻利、隶楷之间 | 讲隶楷之变；看民间文书的书写速度 |

## 5. 证据与限制

- 10 条记录全部 `draft`，待编辑复核。
- 金文记录的是铜器原器，不是拓本；拓本另属实物，未在本批登记。

- 《散氏盘》字数馆方作 350，他处作 357；《毛公鼎》有 497、499、500 三说；记录均保留异说。
- 《郭店楚简》有字简馆方两页作 730 与 731；《武威仪礼简》未见馆方藏品页，枚数与尺寸依报刊。

- 所有新地点无可靠坐标，只作机构名登记，不上地图。
- 未调阅原件、未做拓本对勘、未新增图像。
