**Priority after this batch:** 雁塔圣教序, 好大王碑, 郑文公碑, then four named 龙门 inscriptions and a specific 淳化阁帖 volume. For 化度寺塔铭, the [Palace Museum firsthand study](https://www.dpm.org.cn/historical/talk/205554.html) is a lead for the dispersed Dunhuang rubbing; verify each current holding from its own catalogue before adding it.

**Separate format backlog:** 马王堆帛书, 居延汉简, 兰亭序 and its ink-copy lineages, 快雪时晴帖, 丧乱帖, 智永真草千字文, 书谱, 祭侄文稿, 自叙帖, 古诗四帖, 宋代传世墨迹 (苏轼、黄庭坚、米芾、蔡襄、赵佶), 元代墨迹与题画 (赵孟頫、鲜于枢、邓文原、王冕), and Ming/Qing manuscript selections named by the owner. Broader physical formats need an explicit data-model decision; they are not labelled as steles to fill gaps. Where a genuine recut or rubbing exists, it may be researched separately now.

For every candidate, record the institutional item URL or a consulted print locator, the supported facts, and a separate per-image licence if an image is later used. Downloadability or login access is not a reuse licence.
