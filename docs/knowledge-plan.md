# 知识工程纲领与隶书专题大纲

**任务**：K-004　**分支**：`workbuddy/work`　**日期**：2026-11-25

本文定知识工程的层级、来源规范、七段导读规范与生产流程，并给出第一个学习专题（隶书）的大纲。它是编辑与排期的总纲，不替代 [编辑流程](atlas-workflow.md) 与 [AGENTS.md](../AGENTS.md) 的硬性规则；两者冲突时，以 AGENTS.md 为准。

本文只写规范与大纲，不新建 `knowledge/` 子目录，不改 schema。导读成品写在作品页的 `guide` 与 `## 导读`，不另建文件。

## 一、五层知识体系

五层回答五个不同的问题。层与层之间是“对象—证据—读法—脉络”的关系，不是五个并列的栏目。

| 层 | 回答的问题 | 现有位置 | 最小要求 | 不做什么 |
| --- | --- | --- | --- | --- |
| L1 作品 | 这是什么作品 | `knowledge/works/` | 定名、别名、年代、书体、撰书角色、来源 | 不把某一拓本的经历写进作品 |
| L2 实物 | 是哪一件东西在说话 | `knowledge/objects/` | 实物类型、制作年代、收藏、递藏事件、存佚 | 不把一件拓本的递藏写成原石的经历 |
| L3 证据 | 凭什么这样说 | `knowledge/sources/` 与 `claims` | 可打开的出处、locator、查阅日期 | 不用应用词条、百科、论坛支撑断言 |
| L4 读法 | 怎样读、怎样临 | 作品页 `guide` 与 `## 导读`；`notes/` 只放独立读帖笔记 | 七段结构、字例可指认、审读标记 | 不写无法复核的笔法口诀与“必须” |
| L5 脉络 | 它处在什么位置 | `people/`、`places/`、`relations.md` 与专题大纲 | 人物角色、地点精度、关系方向与 certainty | 不用“风格相似”代替师承或影响证据 |

### 层间规则

1. **作品与实物分离**。一件作品可以有多件实物（原石、明拓、翻刻、摹本）。制作年代、收藏、递藏、存佚属于实物，不属于作品。作品页只写“这是什么”，实物页写“这一件经历了什么”。
2. **证据只向上支撑一层**。来源支撑实物或作品的某个字段，不直接支撑导读里的审美结论。导读的每个事实句仍要回到来源，评价句要回到提出评价的人。
3. **读法层不产生新事实**。`notes/` 与 `guide` 可以组织、解释、比较，但不能引入作品页、实物页和来源里没有的信息。需要新事实时，先回 L1–L3 补记录。
4. **脉络层是索引，不是论证**。人物、地点、关系用于把已有记录连起来；关系的方向与 certainty 必须来自来源，不能从“时代相近”“风格相似”推出来。
5. **专题层只做编排**。专题（如隶书）是 L1–L5 的阅读顺序与练习顺序，不新增数据表；专题里的每一条作品链接都必须指向已存在的稳定 id。

### 与现有目录的对应

- 已有：`works/`、`objects/`、`sources/`、`people/`、`places/`、`notes/`、`relations.md`、`_templates/`。
- 生成页：`README.md`、`catalogue/`、`docs/knowledge-status.md`，不手改。
- 编译产物：`data/index/knowledge-v1.json`，由 `npm run knowledge:compile` 生成，不手改。
- 本纲要不是新目录，落在 `docs/`；分级台账落在 `docs/knowledge-ledger.md`。

## 二、来源使用规范

### 可引与不可引

| 材料 | 可否引用 | 记录方式 | 常见误用 |
| --- | --- | --- | --- |
| 博物馆、图书馆、文物机构、政府页面 | 可 | `kind: web`，URL、发布者、查阅日期、段落或馆号 locator | 把机构页的概述当成保存状况调查 |
| 印本图录、拓本汇编、考古报告 | 可，须实际见到该书 | `kind: book`，出版者、年份、页码或条目号；不编 URL | 只见书名就补页码 |
| 书论、题跋、金石著录 | 可 | 作者、篇名、卷次；转引须写“转引自” | 把转引写成亲见原书 |
| 教学资源、课程记录、公开课 | 限于它所记录的那次使用 | 机构、课程、日期、段落 | 用一次课程证明“通行教法” |
| 碑帖 App、论坛、百科 | 不可作证据 | 只作线索，用来发现碑名与别名 | 用条目里的年份、尺寸支撑断言 |

### 六条硬规则

1. **一条断言一条来源**。同一段里的事实句，逐句能回到 `sources` 中的某条；找不到就删句或写“待考”。
2. **locator 要能落到段、页、馆号**。“该网站有介绍”不算 locator。
3. **查阅日期不是核验日期**。`accessedAt` 只说明哪天打开过页面；原石的保存状况、展厅位置、拓本真伪，未核实就写未核实。
4. **冲突并列，不取平均**。年代、尺寸、行款、作者出现两说时，两说都写，结构化字段留空或取有明确出处的一说并注明异说。
5. **转引分层**。原书、整理本、二手转述分开写；二手转述只能支撑“某人如此说”，不能支撑“事实如此”。
6. **图版与授权**。用馆方图版要记编号或页面；不用来源不明的扫描图；不把图版裁切后当作“原石细部”。

### 与证据等级的关系

- 馆藏著录解决“在哪里、是什么、多大、几行”。
- 书论题跋解决“历来怎样评、谁说过”。
- 学术文献解决“为什么这样看、有没有异说”。
- 三者不能互相替代：一条清人题跋不能证明今天的收藏，一条馆藏页也不能证明清人的评价。

## 三、七步内容生产流程

| 步 | 输入 | 动作 | 产出 | 门禁 |
| --- | --- | --- | --- | --- |
| 1 选题与分级 | 读者来函、展览、专题需要 | 查 `docs/knowledge-ledger.md` 定层级；确认没有重复条目 | 一条任务说明：作品 id、层级、缺口 | 不在没有来源的情况下开工 |
| 2 取证与建源 | 馆藏页、图录、书论 | 每条材料建一个 `sources/` 记录；写 locator 与查阅日期 | 可引用的来源记录 | 来源不可打开或不可核，退回 |
| 3 作品与实物分记 | 来源 | 先写作品，再逐件写实物；事件只挂在实物上 | `works/` 与 `objects/` 记录 | 作品页不出现单件拓本的递藏 |
| 4 关系与地点 | 实物记录、人物资料 | 建人物、地点、关系；坐标只取有出处的机构点 | `people/`、`places/`、`relations.md` | 不用城市中心点代替机构点 |
| 5 七段导读起草 | 前三步的记录 | 在作品页 `guide` 建草稿，按第四节七段规范写进 `## 导读`；每段标证据与待考 | 作品页 `guide`（`state: draft`）与中英成对的 `## 导读` | 03、05 未标审读不得进下一步 |
| 6 审读 | 草稿 | 书法实践者审 03/04/05；编辑核书目与事实；冲突复核 | 审读意见与修改记录 | 审读意见未闭合，保持草稿 |
| 7 编译、检查、交付 | 定稿 | `knowledge:compile` → `knowledge:generate` → `check`；开 PR 写命令与未决问题 | 生成页 diff、检查结果、PR | 检查失败不合并；不手改生成页 |

补充：

- 第 5 步的七段顺序固定，缺证据的段落保留标题写“待考”，不删段。
- 第 5 步只能用现有字段：`guide.state`、`guide.timelineYear`、`guide.people`、`guide.objects`、`guide.sources`，正文只用 `## 导读` / `### 中文` / `### English`；七段标题用 `####`，不新增 YAML 字段。
- 第 6 步的审读人必须是有书法实践的人；审读人不在场时，03/05 只能保持 `待审`。
- 第 7 步的 `knowledge:status` 在新增或改动 `guide` 后会变，需重新生成 `docs/knowledge-status.md`，这是生成页更新，不是手改。
- 一个 PR 只做一个任务；跨任务的改动拆开，避免审读范围混在一起。

## 四、精品导读的七段规范

作品导读不是一个独立文件，而是作品 Markdown 的 `guide:` 前置字段加正文 `## 导读` 段落。现有 schema 只承载导读的状态、时间轴年份、关联人物、关联实物与来源；七段是**正文编辑规范**，用 `####` 标题写在 `### 中文` 与 `### English` 之内，不新增字段。

### 记录头

```yaml
guide:
  state: draft          # 审读前一律 draft
  timelineYear: 156     # 有时间轴意义的年份，整数
  people: []            # 正文实际提到的人物 id
  objects: []           # 正文实际引用的实物 id
  sources: []           # 正文全部外部事实的来源 id
```

### 七段与各段要求

| 段 | 写什么 | 所需证据 | 可留待考 | 审读 |
| --- | --- | --- | --- | --- |
| 01 概述 | 作品是什么、谁在何时为何而作、内容、书体形制、今在何处；第二段回答“为什么现在读它” | 馆藏著录的定名、别名、年代、撰书人、行款、尺寸、额与四面；原址与现藏 | 撰书人无考写“未署名”并说明来源如此；尺寸、行款、碑额各说并列；移置细节归 02 | 以事实为主；写“历来被视为某体代表”须随即给出提出者与出处 |
| 02 历史与流传 | 刻立、原址、移置、损泐、拓本谱系、鉴藏印记、历代著录；按时间顺序，作品／原石／拓本三种对象分开 | 政府或馆方移置记录；图录的题签、藏印、装裱与册页形制；金石著录的书名、卷次、条目 | 只知“约某年”写约；拓本先后无法判定写“待比勘”；未见原书标“待访” | 递藏链每一手要有名字或印记，缺一环就断开，不用“相传”接续 |
| 03 作品赏析 | 书体与结字、章法与行气、书写与刻工、历代品评及依据；先给可核观察，再给评价 | 书论原文（作者、篇名、版本或转引层级）；馆方图版编号或印本页码；对照对象须已收录或注明出处 | 图版不足的细节；两家评语矛盾时并列；刻工改动无法区分时明说 | **全部审美评价须由有书法实践的人审读**；项目判断写 `> 待专业审读：`，古人评语照录署名 |
| 04 典型字例 | 三至六个字例：字、面与行（或图版页）、结构观察、临写要点、选它的理由；覆盖不同结构类型 | 能指到同一字的馆藏图版或印本页码；原石与拓本的字口差异；损泐状态 | 行数或字位不确定写“行数待核”；未见图版不描述点画；只在一件拓本见到的特征不写成原石特征 | 结构分析与临写要点整段须专业审读；未审读只写位置与字形 |
| 05 临习指南 | 选本、读帖顺序、日课、阶段目标、常见问题与自检；先教看，再谈写 | 可得印本或图版信息；有出处的临习传统；公开教学记录 | 字帖版本、课时、工具可留待补；无教学记录的“入门推荐”只能作建议并标审读 | **整段须由有书法实践的人审读后发布**；不写“必须”“唯一”“几天见效” |
| 06 延伸学习 | 同书体、同时代、同地域或同礼制背景的对照；可继续查的馆藏、展览与研究；每条写“为什么对照、看什么” | 本项目已收录可链接的 id；馆方展览页或图录；学术综述 | 未收录写“待收”，不建空链接；展览是否仍在展出须核当时状态 | 对照中的风格判断按 03 处理；只列顺序、不下高下的可免审读标记 |
| 07 研究与文献 | 著录、题跋、论文、图录，按“原书—转引—本项目来源”分层；每条给作者、篇名、卷页、出版信息 | 馆藏著录页；书论篇名；金石著录卷次；论文期刊、年份、页码 | 出版年、出版社、页码未核留空标“待访”；不编 DOI、ISBN、馆藏号 | 不需书法审读，但需一次书目核对：作者、篇名、卷页不能互相矛盾 |

### 写作细则

- 中英成对：`### 中文` 与 `### English` 各写一份七段，英文是中文的翻译，不增事实，不是机器翻译占位。
- 冲突并列，不取平均；结构化字段留空，冲突写进当段与 07。
- 每句事实给链接或“作者《篇名》卷/页”；转引写“转引自”，不伪装成亲见原书。
- `guide.people`、`guide.objects`、`guide.sources` 必须与正文实际引用一致，id 真实存在。
- 审读前 `state: draft`；审读后由审读人确认再改 `reviewed`，实施者不能自审自批。

## 五、待开发需求

七段规范目前只能靠正文约定。编译器只校验 `guide.state`、`timelineYear`、三个 id 列表，以及 `## 导读` 下 `### 中文` 存在且非空；它不认识七段，也不比对中英段数。以下差异不在本批改 schema 或编译器，先记为待开发需求：

| 需求 | 现状 | 影响 | 建议接口（待设计） |
| --- | --- | --- | --- |
| 分节结构化 | 七段只是 `####` 标题，无法被程序识别 | 不能统计某件作品缺哪一段，也不能按段校验 | `guide.sections: [{ id: '01', state, sources, reviewedBy }]` |
| 分节审读状态 | 只有整篇 `guide.state` | 03/05 已审、01 未审时无法表达 | 段级 `state` 或 `reviewedSections: string[]` |
| 段级来源 | `guide.sources` 是整篇列表 | 无法知道某条来源支撑哪一段 | 段级 `sources`，或正文脚注 id |
| 字例结构 | 04 的字例是 Markdown 表格 | 无法校验“字、面、行、图版页”四要素 | `guide.examples: [{ char, face, line, plate, note }]` |
| 审读标记 | `> 待专业审读：` 是纯文本 | 无法阻止未审读内容进发布构建 | 段级布尔标记 + 发布门禁 |
| 多语言对齐 | 中英各一份 `####`，程序不比对 | 可能出现段数或顺序不一致 | 段 id 对齐校验 |

在接口落地前：按第四节写，审读意见写在 PR 与 `guide.state` 的变更记录里；不要自行加字段、改 `readGuide` 或改发布门禁。

## 六、隶书学习专题大纲

### 专题定位

隶书是本项目第一个专题：作品数量够（15 件隶书类记录）、有精品样本（《礼器碑》）、有可对照的简牍与清隶。专题只编排已有记录，不新建作品页。

### 学习目标

学完八节，读者应能：

1. 说清隶书从秦简到东汉碑刻的形态变化，并举出至少两件实物。
2. 分辨“庙堂碑刻”与“摩崖刻石”的行款、用途与阅读方式。
3. 用三个可核字例说明“汉隶极则”一类评语出自谁、依据是什么。
4. 区分作品、原石、拓本三种对象，不在同一段里混用它们的经历。
5. 完成一次八周临写记录，能对自己的结构、波磔、章法作可复核的描述（须经审读）。

### 前置要求

- 读过 `docs/atlas-workflow.md` 的“什么算来源”。
- 会用馆藏页的图版编号定位一个字。
- 愿意把“好看/不好看”改写成“哪一笔、在哪个位置、与哪一件对比”。

### 八节顺序

每节的“字例”只列本项目已核到的字；未核的一律写“待定”，并给出选字标准。不凭记忆填名碑字例。

#### 第 1 节　隶书的边界与隶变

- **关联作品**：[睡虎地秦简](../knowledge/works/shuihudi-qinjian.md)、[五凤刻石](../knowledge/works/wufeng-inscription.md)、[武威仪礼简](../knowledge/works/wuwei-yili-jian.md)
- **字例**：待定。选字标准：简与刻石各取一例，能看出同一字在“手写”与“刻制”中的差别。
- **练习任务**：把三件实物按年代排一条线；各写一句“它为什么被称作隶书”，句句注明来源；再写一句“还不能确定什么”。
- **参考来源类型**：馆藏著录、简牍整理报告、考古报告、书法史专著。

#### 第 2 节　庙堂隶书：孔庙三碑

- **关联作品**：[乙瑛碑](../knowledge/works/yiying-bei.md)、[礼器碑](../knowledge/works/liqi-bei.md)、[史晨碑](../knowledge/works/shichen-bei.md)
- **字例**：《礼器碑》“绝思”（故宫明拓本二字未损连，属版本字口，不是笔画示范）；其余待定。
- **练习任务**：数三碑的碑阳行款并记下出处；在《礼器碑》碑阳、碑阴、碑侧各找一个题名，画出它们在石面的位置；写 300 字读碑记，事实句带出处。
- **参考来源类型**：曲阜汉魏碑刻陈列馆与孔子博物馆的馆藏页、山东宣传网的“孔庙三碑”专文、清人题跋。

#### 第 3 节　秀逸与方整：曹全、张迁

- **关联作品**：[曹全碑](../knowledge/works/cao-quan-bei.md)、[张迁碑](../knowledge/works/zhangqian-bei.md)
- **字例**：待定。选字标准：两碑各选三字，结构类型对应（独体、左右、上下），且在图版上能指到同一位置。
- **练习任务**：各临十字，做两张“描述卡片”，只写结构比例、笔画起止、字距行距，不写“秀”“拙”一类结论；结论留到审读课。
- **参考来源类型**：西安碑林与故宫的馆藏著录、岱庙相关记录、清代隶书论。

#### 第 4 节　摩崖：石门颂、西狭颂

- **关联作品**：[石门颂](../knowledge/works/shimen-song.md)、[西狭颂](../knowledge/works/xixia-song.md)
- **字例**：待定。选字标准：选因石面不平而字形变形的字，能说明“因石布字”的位置。
- **练习任务**：在拓本或照片上标三处行距不匀的地方，写清“石面怎样影响了这一行”；比较摩崖与庙堂碑的阅读距离。
- **参考来源类型**：汉中市、汉台区政府页与文物部门资料、金石著录、摩崖调查报告。

#### 第 5 节　规范与官方书写：熹平石经、石台孝经

- **关联作品**：[熹平石经](../knowledge/works/xiping-stone-classics.md)、[石台孝经](../knowledge/works/shitai-xiaojing.md)
- **字例**：待定。选字标准：同一字在石经与唐隶中各取一例，能看出“规范”与“后世隶书”的差别。
- **练习任务**：写一段说明“石经为什么刻、给谁看”，只用馆藏著录与学术文献；比较两碑的碑石形制与陈列方式。
- **参考来源类型**：中国国家博物馆与西安碑林的馆藏页、石经研究、唐代制度史文献。

#### 第 6 节　隶楷之间：爨宝子、好太王碑、走马楼吴简

- **关联作品**：[爨宝子碑](../knowledge/works/cuan-baozi-bei.md)、[好太王碑](../knowledge/works/haotaiwang-bei.md)、[走马楼吴简·嘉禾吏民田家莂](../knowledge/works/zoumalou-wujian.md)
- **字例**：待定。选字标准：选结构仍近隶、笔画已近楷的字，注明判断依据。
- **练习任务**：写 200 字回答“凭什么说一件作品在隶楷之间”，分结构与笔画两项；把“像楷书”改成可核的描述。
- **参考来源类型**：云南、吉林等省级馆页与方志、长沙简牍博物馆资料、书法史专著。

#### 第 7 节　清隶与少字数创作：伊秉绶

- **关联作品**：[隶书五字横幅](../knowledge/works/yi-wuzi.md)
- **字例**：待定。横幅字数少，须据馆藏图版逐字核定后再列。
- **练习任务**：以横幅为参照，做一次五字临作；记录纸、墨、笔与字号；写一段“为什么少字数更难藏拙”（审读后）。
- **参考来源类型**：馆藏著录、清代隶书研究、书家年谱。

#### 第 8 节　综合读临：以《礼器碑》为中心的八周

- **关联作品**：[礼器碑](../knowledge/works/liqi-bei.md)（主）、[曹全碑](../knowledge/works/cao-quan-bei.md) 与 [张迁碑](../knowledge/works/zhangqian-bei.md)（对照）、[衡方碑](../knowledge/works/hengfang-bei.md)（字口对照）
- **字例**：《礼器碑》“绝思”（版本字口）；《衡方碑》“将”“仪之”（拓本存字情况，据馆藏著录）；其余待定。
- **练习任务**：八周记录，每周一次：读一行、临一行、记一条字口或行款、写一句自评；第八周交一篇 800 字读帖报告，事实句带出处，评价句标“待审读”。
- **参考来源类型**：全部五类；以馆藏著录与清人题跋为主，学术文献用于解释异说。

### 评估方式

| 项目 | 权重 | 判准 |
| --- | --- | --- |
| 事实与出处 | 40% | 每个事实句能回到来源；冲突并列；没有编造 |
| 字例与图版 | 25% | 字例能指到同一面、同一行或同一图版页 |
| 临写记录 | 20% | 八周连续；描述可复核；不写“必须”“唯一” |
| 自评与审读 | 15% | 能区分自己的判断与来源的评价；审读意见有回应 |

### 专题缺口

1. **清隶只有 1 件**（伊秉绶横幅），不足以支撑“清隶复兴”的完整叙述；需另选作品补记录后再扩第 7 节。
2. **简牍字例未核**。睡虎地、居延、武威、走马楼四件只有释文层面的来源，字例要等图版核对。
3. **《曹全碑》年代与尺寸有异说**（185/186；碑宽 95/123 厘米），第 3 节须先讲清两说，不能替读者选一个。
4. **唐隶样本少**。石台孝经一件不足以概括唐隶，第 5 节只作“官方书写”的个案。
5. **没有隶书专题的馆藏展览线索**。孔子博物馆 2023 年的展览报道只能证明当时展过，不能证明现在仍在展。

## 七、执行顺序与验收

1. 先做精品 10 件的七段导读，每件一个 PR；《礼器碑》已在作品页 `guide` 出中英草稿，作为七段规范的第一个实测样本。
2. 每完成 3 件，复核一次 `docs/knowledge-ledger.md` 的名额与理由，必要时升降级。
3. 核心 30 件先补“第二条来源 + 三个字例”，再决定是否升精品；不跳过补证直接写七段。
4. 隶书专题在第 2、3、8 节有成品导读后再排课；没有成品页之前，大纲只作内部排期。
5. 每次数据改动后跑 `npm.cmd run knowledge:compile && npm.cmd run knowledge:generate`，再跑 `npm.cmd run check`；新增笔记后补跑 `npm.cmd run knowledge:status` 更新生成页。
