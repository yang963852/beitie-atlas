## 2. 下一阶段的目标

读者打开一部作品，应该能完成三件事：

1. **读得进**：知道这是什么、为什么现在读、先看哪一件实物。
2. **查得到**：从作品进入书家、读帖笔记、相关作品和馆藏记录。
3. **信得过**：每条事实能回到来源；异说并列；未知留白。

写作原则：

- 读者路径优先，不做百科式堆料。
- 证据先于篇幅：一条断言一条来源；找不到就删句或写“待考”。
- 中文原稿；英文同义翻译，不增事实，不机翻占位。
- 不写无出处的审美评价、临习处方、年代、尺寸或坐标。
- 一次只做一个批次；不在同一 PR 里跨批次改。

**目标**：让馆藏地图从“6 个示意点”变成“主要馆藏可查”。

**做什么**：给 14 个主要馆藏机构补坐标，使有坐标地点达到 20/46。优先：故宫博物院、西安碑林博物馆、中国国家图书馆、上海博物馆、辽宁省博物馆、天津博物馆、曲阜汉魏碑刻陈列馆、泰安市博物馆、汉中市博物馆、宝鸡青铜器博物院、昭陵博物馆、晋祠、岱庙、东京国立博物馆。

**规则**：

**产出目标**：20/46 地点有坐标；地图列表与详情口径一致。

## 4. 每批的交付方式

- 一个批次一个 PR；不把 Batch 1 和 Batch 2 混在一起。
- PR 写明：改了哪些文件、用了哪些来源、哪些问题仍留空、指标变化。
- 运行：

```powershell
npm.cmd run knowledge:compile
npm.cmd run knowledge:generate
npm.cmd run check
npm.cmd run check:release
```

- 提交生成目录的 diff（`knowledge/catalogue/`、`knowledge/README.md`）；不手改 `data/index/knowledge-v1.json`。
- 自审即可，负责人合并；不需要独立审阅或交付报告。

## 5. 不能做什么

- 不新增作品、实物、人物或地点来“凑规模”；新增条目另开批次，先有来源。
- 不把碑帖 App、论坛、百科当证据；它们只能做线索。
- 不写没有出处的“最”“第一”“必学”“几天见效”。
- 不把原石、拓本、摹本混为一件；不把原石的经历复制给拓本。
- 不猜坐标、不猜年份、不补尺寸、不编 DOI/ISBN/馆藏号。
- 不机翻；英文缺失时保留中文，不生成占位译文。
- 不删除已有的异说与待考；冲突并列。
- 不改 `src/`、`scripts/`、`data/index/`；需要新字段时先提给负责人和 TRAE。
