# 碑帖之间 · Between Steles

> 本文件与 [English version](PROJECT.en.md) 共同构成项目理念的唯一权威文本。其他文档只作简要介绍并链接到这里，不复制全文；修改理念时两份文件须同步更新，中文原意与英文译文保持一致。
>
> 理念独立于网站功能、技术架构和版本迭代。

## 初心

从案头所临的一件碑帖出发，追寻它的历史、流传与书写之美，认识作品背后的书家、时代与文化。
我们因书法而相聚，也希望将学习、实践、思考与讨论中的所得分享给更多的人。

## 使命

让书法走向大众。
书法不应只是少数专业人士的艺术，也可以成为普通人认识历史、感受美、表达自我和丰富精神生活的一种方式。
我们相信，对美的理解并非与生俱来，而是在学习、实践与交流中逐渐形成的。即使不以艺术成就为目标，书写与欣赏的过程本身也具有价值。

## 定位

碑帖之间是一个由书法爱好者共同建设的、开放共享的书法知识项目，主要面向书法初学者与爱好者。
以经典碑帖为起点，整理作品、书家、传世实物、历史流传、研究文献及临习经验，为书法学习提供可靠、易读、相互关联的公共知识。
我们提供知识与学习引导，但不试图替代人与人之间的教育。
碑帖是认识书法的起点，而非项目永远的边界。

## 理念

**人人为我，我为人人。**

- 开放共享：让知识能够被自由阅读、学习、使用与继续建设。
- 尊重事实：重视出处与证据，允许异说并存，承认未知。
- 尊重个体：珍视每个人真实的学习体验、审美判断与独立思考。
- 学习共建：不仅积累学习的成果，也记录学习、讨论与探索的过程。
- 人是主体：技术与人工智能服务于人的学习、表达和协作，而非取代人的体验与判断。
- 保持热爱：不以规模、流量或世俗意义上的成功作为建设项目的目的。

## 共建

我们欢迎任何热爱书法、愿意分享的人参与，无论其学习阶段、专业背景或技术能力。
项目由维护者承担建设、管理与发布责任，同时尊重贡献者的自主性，支持他们利用项目资源开展学习、研究、交流及相关文化活动。

## 愿景

成为一个能够长期积累、自由共享、持续共建的书法公共文化项目。
让每一个对书法感兴趣的人，都能够从中有所获得，也有机会将自己的所得留给后来者。
我们不急于抵达某个终点，只希望在热爱的道路上，与更多的人同行。
